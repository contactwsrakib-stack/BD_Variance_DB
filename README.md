# 📊 Democratizing Public Procurement: Civic Tech Dashboard

**[Live Interactive Dashboard](https://procurementvariancedashboard.netlify.app/)** | **[Read the Full Research Paper](https://docs.google.com/document/d/1q3q3aoR8ftDOBvK5GYyL0TEV1_vDSWC7O_vHzqmHCXM/edit?tab=t.0)**

## 🌍 The Problem
In developing economies, state procurement represents a massive allocation of taxpayer funds. However, citizens and watchdog organizations often lack real-time access to Open Government Data (OGD) regarding public expenditure variances. This creates a profound information asymmetry, allowing severe cost overruns on state contracts and infrastructure mega-projects to remain hidden from the public eye.

## 💡 The Solution
This project is a web-based **Civic Tech Dashboard** designed to aggregate, track, and visualize Purchase Price Variances (PPV). By transforming scattered, obscure financial data into accessible public insights, this tool bridges the gap between state institutions and the public, fostering evidence-based accountability.

## 🛠️ Technology Stack
* **Frontend:** React.js, Vite
* **Styling:** Tailwind CSS (Dark Mode optimized for analysts)
* **Data Visualization:** Recharts
* **Deployment:** CI/CD via Netlify 

## 🚀 How to Run Locally
If you want to clone this repository and run it on your own machine:

1. Clone the repo:
   `git clone https://github.com/contactwsrakib-stack/BD_Variance_DB.git`
2. Install dependencies:
   `npm install`
3. Start the development server:
   `npm run dev`
